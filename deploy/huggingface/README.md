# Jewellery Analyzer

Upload a jewellery image to classify it (earring / necklace) and generate a
description with a VGG-16 encoder and GRU decoder trained on 32,190 images.

Source code, notebooks and project report:
https://github.com/chandana-galgali/Automated-Caption-Generation-using-Encoder-Decoder-Model-for-Jewellery-Images
